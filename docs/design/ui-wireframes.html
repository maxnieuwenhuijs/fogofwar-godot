Fog of War — UI wireframes (low-fi)

Layout intent only — no styling. Read together with UI-SPEC-EN.md (what every element shows/does) and the visual-direction brief. Portrait 1080×1920. Solid boxes = static chrome, dashed cream boxes = dynamic content, rounded grey = tappable. The multiplayer campaign is the main focus: frames 3–9 are designed for 16 humans (solo vs bots reuses them unchanged); frames 13–16 are the multiplayer-specific screens.
